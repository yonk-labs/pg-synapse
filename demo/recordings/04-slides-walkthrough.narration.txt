[Slide 4] [sigh] Why put a loop in the database at all? Because right now the agent lives next door, and that's where the trouble starts. [Slide 5] [confident] Flip it around, and put the loop where the decisions are. Governance comes for free, because tool SQL runs under Postgres privileges, and permission denied is just the database doing its job. Inline mode keeps the decision inside the writing transaction: if the agent says no, the insert rolls back, with a reason attached. Tool calls stay in-process, which leaves the model call as the one external hop. Agents are rows, so you change them with SQL and pg dump takes them along. Runs land in tables you can query.
